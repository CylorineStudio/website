隐私政策 ​

生效日期： 2026 年 3 月 13 日
最后更新日期： 2026 年 5 月 14 日

欢迎使用 Cylorine Studio（以下简称“我们”、“我们的”）提供的产品与服务。我们高度重视用户隐私保护，并承诺以清晰、透明的方式说明我们如何处理您的信息。请您在使用我们的产品与服务前，仔细阅读并充分理解本隐私政策的全部内容。

1. 信息收集范围 ​

我们遵循最小必要原则，不主动收集任何可直接识别个人身份的信息（如姓名、地址、电话号码等）。在您访问我们的官方网站或使用我们的软件（包括但不限于 PCL.Mac）时，以下技术信息可能被自动记录：

  • 软件版本信息：当您的软件向我们的 API 发送请求时，请求中会包含软件名称及版本号（例如 PCL-Mac/1.0.0），用于识别软件版本以提供相应服务。
  • 网络日志信息：包括 IP 地址及请求时间。此类信息是互联网通信的常规记录，仅用于保障服务安全与稳定运行，我们不会将 IP 地址用于定位或识别具体个人。
  • 网站访问信息：我们的官方网站托管于 GitHub Pages 平台。GitHub 可能自动收集标准的服务器访问日志（如浏览器类型、访问时间、来源页面等）。该等信息由 GitHub 按其隐私政策处理，我们无法直接访问或控制。详情请参阅 GitHub 隐私声明。

2. 信息使用目的 ​

我们仅将收集的信息用于以下合法目的：

  • 提供服务与功能：确保软件正常运行，例如检查更新、获取公告等。
  • 改进与优化：统计软件使用人数及版本分布，分析用户需求，优化产品性能与用户体验。

3. 信息共享与披露 ​

我们承诺不会出售、出租或交换您的任何信息。仅在法律要求或为履行法定义务所必需时，我们可能在合法范围内配合有权机关的要求披露相关信息。

4. 数据跨境传输 ​

鉴于我们的 API 服务器位于境外，您使用软件时发出的请求将涉及数据跨境传输。我们已采取必要的技术措施（如 HTTPS 加密）确保传输过程的安全性，并选择符合行业标准的境外服务提供商。

5. 数据安全保护 ​

我们采用 HTTPS 加密协议等技术手段保护数据传输过程中的安全，防止信息被未经授权地访问、泄露、篡改或毁损。但请注意，尽管我们竭尽全力保护您的信息安全，任何互联网传输方式都无法保证绝对安全。

6. 用户权利 ​

根据适用法律法规，您有权知悉您的信息如何处理。由于我们不收集可直接识别个人的信息，因此无法提供特定个人的数据副本或删除特定数据。如您对本隐私政策或数据处理有任何疑问，可通过第 9 条列明的方式联系我们。

7. 第三方链接 ​

我们的网站或软件可能包含指向第三方网站或服务的链接（例如 GitHub）。点击该等链接将离开我们的服务范围，我们对第三方的隐私实践不承担任何责任，建议您查阅其隐私政策。

8. 隐私政策的更新 ​

我们可能不时修订本隐私政策，以反映业务实践或法律法规的变化。更新后的隐私政策将在本页面公布，并注明最后更新日期。我们建议您定期查阅本页面以获取最新信息。重大变更我们可能通过网站公告或软件内通知等方式另行告知。

9. 联系我们 ​

如您对本隐私政策有任何疑问、意见或建议，欢迎通过以下方式联系我们：

  • 电子邮箱：org@ceciliastudio.top 或 yizhimcqiu@icloud.com

我们将尽快审核所涉问题，并在合理期限内予以回复。
