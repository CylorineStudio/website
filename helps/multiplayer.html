教程：多人联机 ​

独乐不如众乐，让好友加入你的 Minecraft 游戏世界！

下面按照上手难度从低到高介绍几种 Minecraft Java 版联机方式。如果你和好友在同一 WiFi 下，直接使用游戏内置联机即可；如果身处异地，推荐按以下顺序尝试：启动器自带联机 → 虚拟局域网工具 → FRP 内网穿透。

方式 ​

游戏内置联机 ​

使用 Minecraft 自 Classic 0.0.15a 就加入的联机功能进行联机。

要求 ​

  • 所有玩家都在同一局域网内

步骤 ​


房主 ​

  1. 启动 Minecraft 并进入世界。

  2. 按下 ESC 打开游戏菜单，随后：
    对于 26.2 以前的版本：点击「对局域网开放」→「创建局域网世界」。
    对于 26.2 及以后的版本：点击「对局域网开放」，开启上方的「局域网」选项，并点击「应用更改」。

    如果有成员没有正版账号，房主需要安装 Lan Server Properties 或 LAN World Plug-n-Play 模组，并在创建局域网世界时关闭「正版验证」或「在线验证」等选项。

  3. 端口号将显示在聊天栏，高版本点击端口号可复制。

  4. 获取内网 IP 地址：
    对于 Windows：按下 Win + R 打开运行框，输入 cmd 并按回车，随后在 cmd 中输入 ipconfig | findstr "IPv4" | findstr /v "127.0.0.1" 并执行，后面的数字就是你的内网 IP 地址。
    对于 macOS 或 Linux：在终端执行 ifconfig | grep -E "([0-9]{1,3}\.){3}[0-9]{1,3}" | grep -v 127.0.0.1 | awk '{print $2}' 命令，输出即为你的内网 IP 地址。
    地址看起来应该像这样：10.1.1.4 或 192.168.1.145。

成员 ​
  1. 启动 Minecraft，点击「多人游戏」。
  2. 如果列表中显示了局域网世界，直接双击加入即可。
  3. 点击「直接连接」，输入房主的 地址:端口（如 192.168.1.145:14191）并点击加入服务器。

支持 Scaffolding 协议的启动器 ​

使用实现了 Scaffolding-MC 协议的启动器中内置的联机功能进行跨局域网联机。

包括但不限于：

  • HMCL（教程视频）
  • PCL CE
  • FCL（教程视频）
  • PCL.Mac（由于节点问题，联机功能暂时不可用，请等待恢复）

步骤与游戏内置联机相似。

注：部分启动器的联机使用 NAT 穿透技术，成功率取决于双方 NAT 类型。如果一直无法成功联机（启动器内报错或卡在正在加入房间），请使用其它方式。

FRP ​

FRP（Fast Reverse Proxy）是一个开源的内网穿透工具，可以将你电脑上的游戏端口映射到公网服务器，让外网成员通过公网地址直接连接。FRP 客户端（frpc）支持 Windows、macOS 与 Linux。

下面推荐两种方案：免费 FRP 服务（零成本、无需自备服务器）和自行搭建（灵活可控、需要一台有公网 IP 的 VPS）。

免费 FRP 服务（推荐：SakuraFrp） ​

SakuraFrp（樱花内网穿透）是国内广泛使用的免费 FRP 服务，提供 Windows、macOS、Linux 启动器，支持流量签到获取免费额度，足以满足日常联机需求。

要求 ​
  • 房主注册 SakuraFrp 账号，完成实名认证（免费用户需每日签到获取流量）
步骤 ​

房主 ​

  1. 前往 SakuraFrp 下载页，下载对应平台的启动器：

    • 对于 Windows：下载 .exe 安装包，双击按向导完成安装。
    • 对于 macOS：下载 .dmg 镜像安装（需 macOS 13 及以上；更低版本请参考 SakuraFrp Docker 部署 或使用命令行 frpc）。
    • 对于 Linux：下载 .AppImage 或对应发行版的安装包，赋予执行权限后运行。

  2. 启动 SakuraFrp 启动器并登录账号。

  3. 按照游戏内置联机的步骤开启局域网世界。

  4. 在启动器中点击「创建隧道」，填写以下信息：

    • 隧道类型：选择 TCP。
    • 隧道名称：任意填写（如「Minecraft 联机」）。
    • 本地 IP：填写 127.0.0.1。
    • 本地端口：填写 Minecraft 聊天栏显示的端口号。
    • 远程端口：保持默认或选择一个未被占用的端口。

  5. 点击「创建」并启动隧道。隧道启动后，启动器会显示连接地址（类似 frp-xxx.com:12345）。将这个地址发给成员。

成员 ​
  1. 启动 Minecraft，点击「多人游戏」→「直接连接」。
  2. 输入房主提供的地址（如 frp-xxx.com:12345），点击加入服务器。

自行搭建 FRP ​

如果你拥有一台有公网 IP 的云服务器（VPS），可以自行部署 FRP，获得完全的自主控制权。自建 FRP 需要一定的服务器运维经验，详细配置请参考 FRP 官方文档 或社区教程 「一文搞懂 FRP」。

VPN / 虚拟局域网 ​

虚拟局域网（Virtual LAN）工具可以在互联网上创建一个虚拟的局域网，让所有加入的玩家就像在同一路由器下一样直接联机。此类工具大多基于 P2P 直连，延迟低，设置简单。

Radmin LAN（蓝盾） ​

Radmin LAN（国内俗称「蓝盾」）是国内最流行的游戏虚拟局域网工具，永久免费、不限流量、无需注册账号，点击创建即可使用。官方仅支持 Windows，macOS 与 Linux 用户请使用下方的蒲公英。

步骤 ​

所有玩家 ​
  1. 前往 Radmin LAN 下载页 下载 Windows 客户端并安装。
房主 ​
  1. 打开 Radmin LAN，点击「创建网络」，设置网络名称和密码，点击创建。
  2. 将网络名称和密码发给成员。
  3. 记下 Radmin LAN 主界面中房主的虚拟 IP 地址。
  4. 启动 Minecraft 并进入存档，按照游戏内置联机的步骤对局域网开放。
  5. 将 虚拟IP:端口（如 26.0.0.1:14514）发给成员。
成员 ​
  1. 打开 Radmin LAN，点击「加入网络」，输入房主提供的网络名称和密码。
  2. 启动 Minecraft，点击「多人游戏」→「直接连接」。
  3. 输入房主提供的 虚拟IP:端口，点击加入服务器。

蒲公英（贝锐） ​

蒲公英 是贝锐旗下的异地组网工具，跨平台支持 Windows、macOS、Linux、Android、iOS。免费版支持 3 个客户端，适合 2-3 人联机。

步骤 ​

所有玩家 ​

  1. 前往 蒲公英下载页 下载对应平台的客户端并安装：

    • 对于 Windows：下载 .exe 安装包。
    • 对于 macOS：下载 .dmg 安装包。
    • 对于 Linux：下载对应发行版的安装包（.deb / .rpm）。

  2. 注册贝锐账号，登录蒲公英客户端。

房主 ​
  1. 在蒲公英客户端中创建网络，将成员账号添加进网络（或分享网络 ID 让成员加入）。
  2. 成员加入后，在客户端中找到房主设备的虚拟 IP 地址（如 172.16.x.x）。
  3. 启动 Minecraft 并进入存档，按照游戏内置联机的步骤对局域网开放。
  4. 将 虚拟IP:端口（如 172.16.0.5:14191）发给成员。
成员 ​
  1. 确保已加入房主的网络。
  2. 启动 Minecraft，点击「多人游戏」→「直接连接」。
  3. 输入房主提供的 虚拟IP:端口 并加入服务器。

免费版限制 3 个客户端，2-3 人联机刚好够用。如需更多人联机，可付费升级或使用上方的 FRP 方案。

总结 ​

以上几种方式各有侧重。如果所有人都在同一局域网，游戏内置联机最为简单。异地联机时，优先尝试启动器自带的联机功能；如果不可用或连不上，Radmin LAN（蓝盾） 对 Windows 用户最友好，蒲公英则可覆盖全平台。若以上方案均不满足需求，FRP 是最灵活可靠的选择——既可使用免费的 SakuraFrp，也可自建服务端获得完全控制权。
