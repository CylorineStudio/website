PCL.Mac


PCL.Mac 是 Plain Craft Launcher（由龙腾猫跃制作的 Minecraft 启动器）的非官方重构版，使用 SwiftUI 框架完全重构了 PCL 以支持 macOS。

如果你遇到了游戏报错、无法加载等问题，欢迎前往用户群获取帮助。

如果你遇到了可复现的启动器 Bug（而不是临时错误或 Minecraft 本身的问题），或想提出一个功能建议，请前往 GitHub 提交 Issue。

请不要在 PCL 官方版本 / 其它版本相关仓库或群聊中反馈关于 PCL.Mac 的问题。

帮助文档：PCL.Mac 帮助文档 与 FAQ

下载 ​

你可以在 GitHub Releases、CNB Releases（国内镜像）或 用户群 中下载 PCL.Mac。
